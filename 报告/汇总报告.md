## 一、项目背景与目的

### 1.1 项目背景与目的

图像分类是计算机视觉中最基础也最核心的任务之一，其目标是判断一张输入图像所属的语义类别，是目标检测、图像分割等更复杂任务的基础。在深度学习兴起之前，图像分类主要依赖手工设计的特征（如 SIFT、HOG）与传统的机器学习分类器，泛化能力有限。2012 年 AlexNet 在 ImageNet 竞赛中取得突破后，卷积神经网络（CNN）凭借自动学习层次化特征的能力，成为图像分类的主流方法。

本项目的目的是：基于 CIFAR-10 数据集，实现并对比两种卷积神经网络分类方案——从零搭建的 SimpleCNN 与基于 ImageNet 预训练的 ResNet18 迁移学习，完整实践「数据处理 → 模型构建 → 训练 → 评估」的图像分类全流程，并深入理解 CNN 与迁移学习。

### 1.2 问题描述与难点分析

本任务可形式化描述为：给定一张 32×32 的彩色图像 x，预测其所属类别 y ∈ {飞机, 汽车, 鸟, 猫, 鹿, 狗, 青蛙, 马, 船, 卡车}（共 10 类）。主要难点有：

1. **图像尺寸小**：32×32 分辨率下信息有限，物体细节和纹理不如自然图像丰富。
2. **数据量相对有限**：每类仅 5000 张训练样本，从零训练容易过拟合。
3. **类别间相似性**：「猫 / 狗 / 鸟」等类别外形相似，容易混淆，是分类错误的主要来源。

### 1.3 方法选择与分析

- **为什么选 CNN**：CNN 通过卷积核在图像上滑动提取局部特征，具有参数共享与局部连接两大特性，能自动学习从边缘、纹理到物体部件的高层特征，是目前图像分类的最优选择。
- **为什么选 PyTorch**：PyTorch 生态完善、API 直观、GPU 加速方便，且 torchvision 提供了 CIFAR-10 数据集与 ImageNet 预训练模型的便捷接口。
- **为什么做两种方案对比**：通过「从零训练 vs 迁移学习」的对照，可以直观验证预训练特征在小规模数据集上的价值，这正是本实验的核心结论。

## 三、数据准备与处理

### 3.1 数据集获取

实验采用 CIFAR-10 数据集，通过 torchvision 的 `datasets.CIFAR10` 接口自动下载。数据集包含 60000 张 32×32 彩色图像，共 10 个类别（飞机、汽车、鸟、猫、鹿、狗、青蛙、马、船、卡车），训练集 50000 张、测试集 10000 张，每类均衡。由于官方源（多伦多大学服务器）在国内下载极慢，本项目使用了国内镜像手动下载并校验 MD5。

### 3.2 数据预处理

- **归一化**：像素值经 `ToTensor` 缩放到 [0,1] 后，按通道减去均值、除以标准差，使输入近似标准正态分布，加速收敛。SimpleCNN 使用 CIFAR-10 自身统计量（均值 (0.4914, 0.4822, 0.4465)、标准差 (0.2023, 0.1994, 0.2010)）；ResNet18 使用 ImageNet 统计量（均值 (0.485, 0.456, 0.406)、标准差 (0.229, 0.224, 0.225)），与预训练权重保持一致。
- **尺寸调整**：ResNet18 的预训练权重基于 224×224 输入，故将 32×32 图像上采样到 224×224；SimpleCNN 直接使用 32×32。

### 3.3 数据增强实现

训练集应用了两种数据增强以抑制过拟合：**随机水平翻转**（以 0.5 概率左右翻转）与**随机裁剪**（先四周补 4 像素再随机裁回 32×32）。测试集不做增强，仅归一化，保证评估公平。

### 3.4 数据集划分

沿用 CIFAR-10 官方划分（训练 50000 / 测试 10000）。使用 PyTorch 的 `DataLoader` 组织数据，训练集随机打乱，SimpleCNN 批大小为 128，ResNet18 微调时批大小为 64（受显存限制），采用多进程加速数据读取。

## 四、模型构建与算法实现

### 4.1 整体实现流程

项目整体 Pipeline 为：**读取数据 → 归一化与数据增强 → 前向传播得到类别得分 → 计算交叉熵损失 → 反向传播更新参数 → 测试集评估**。代码按模块组织为 `data.py`（数据）、`model.py`（模型）、`train.py`（训练）、`evaluate.py`（评估），由 `run_all.py` 一键串联。

### 4.2 所用模型/算法原理

**SimpleCNN**：主体由三个卷积块堆叠而成，每个块为「卷积 → 批归一化 → ReLU → 最大池化」，通道数 32→64→128，空间尺寸 32→16→8→4，随后展平接 256 维全连接隐层（Dropout 0.5）和 10 类输出层，参数量约 160 万。它作为从零训练的基线模型。

**ResNet18 迁移学习（微调）**：ResNet18 是经典残差网络，通过跳跃连接（skip connection）缓解深层网络的梯度消失问题。迁移学习是指把在大规模数据集上学到的知识迁移到目标任务。本项目加载 ImageNet 预训练的 ResNet18，将其最后一层全连接层替换为输出 10 类的分类头，然后在 CIFAR-10 上以合适的学习率对**整个网络进行微调**，让预训练特征适应目标任务。

### 4.3 关键代码展示

**（1）SimpleCNN 网络结构（节选）**

```python
class SimpleCNN(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 32, 3, padding=1), nn.BatchNorm2d(32),
            nn.ReLU(inplace=True), nn.MaxPool2d(2),   # 32->16
            nn.Conv2d(32, 64, 3, padding=1), nn.BatchNorm2d(64),
            nn.ReLU(inplace=True), nn.MaxPool2d(2),   # 16->8
            nn.Conv2d(64, 128, 3, padding=1), nn.BatchNorm2d(128),
            nn.ReLU(inplace=True), nn.MaxPool2d(2),   # 8->4
        )
        self.classifier = nn.Sequential(
            nn.Flatten(), nn.Linear(128 * 4 * 4, 256),
            nn.ReLU(inplace=True), nn.Dropout(0.5), nn.Linear(256, num_classes),
        )
    def forward(self, x):
        return self.classifier(self.features(x))
```

**（2）加载 ImageNet 预训练 ResNet18 并替换分类头**

```python
from torchvision.models import resnet18, ResNet18_Weights
model = resnet18(weights=ResNet18_Weights.IMAGENET1K_V1)  # 加载预训练权重
model.fc = nn.Linear(model.fc.in_features, 10)            # 1000 类 -> 10 类
```

**（3）训练循环核心（节选）**

```python
outputs = model(images)                      # 前向传播
loss = criterion(outputs, labels)            # 交叉熵损失
optimizer.zero_grad()
loss.backward()                              # 反向传播
optimizer.step()                             # 更新参数
```

## 五、模型训练与调优过程

### 5.1 训练参数设置

两个模型均使用交叉熵损失（CrossEntropyLoss）与 Adam 优化器，配合余弦退火学习率调度逐步衰减学习率。

| 参数 | SimpleCNN | ResNet18 |
|---|---|---|
| Epoch | 20 | 15 |
| Batch Size | 128 | 64 |
| 初始学习率 | 1e-3 | 1e-3 |
| 优化器 | Adam | Adam |
| 学习率调度 | 余弦退火 | 余弦退火 |

### 5.2 训练过程监控

训练过程中每个 epoch 结束后在测试集上评估，记录训练/测试的损失与准确率，并绘制曲线（见 `results/*/training_curves.png`）。从曲线可以看出：SimpleCNN 从零学习，损失逐步下降、准确率稳步上升；ResNet18 因预训练权重已具备良好特征，收敛更快、最终精度更高。

### 5.3 调优记录

调优过程共经历了三次尝试，前两次均未达到预期，最终通过分析原因修正：

1. **方案一：冻结骨干，仅训练分类头**。最初将 ResNet18 的卷积骨干全部冻结，只训练替换后的分类层，期望借预训练特征快速收敛。结果测试集准确率约 81%，与从零训练的 SimpleCNN 差距不大。分析认为：ImageNet 特征与 32×32 上采样得到的 CIFAR-10 小图差异较大，冻结的特征不够贴合，仅靠分类头难以发挥。

2. **方案二：全量微调，但学习率过低**。改为不冻结骨干、全量微调，但按「微调要用小学习率」的直觉把学习率设为 1e-4，并配合余弦退火。结果训练到第 3~4 个 epoch 后准确率就停滞在约 81%，后续几乎不再提升。分析认为：1e-4 对 Adam 优化器而言偏低，且余弦退火让学习率持续衰减，中后期「学不动」。

3. **方案三：全量微调，学习率 1e-3**。把学习率调回 Adam 的常规取值 1e-3，训练 15 个 epoch。预训练权重作为良好初始化，网络在少量轮次内即适应 CIFAR-10，测试集准确率提升至约 95.18%，显著优于前两个方案。

这段「冻结 → 低学习率微调 → 合适学习率微调」的对比说明：迁移学习中冻结特征往往不够，需要全量微调；而微调的学习率也要合适——过小会导致收敛停滞。

## 七、总结与心得体会

### 7.1 项目成果总结

本项目基于 CIFAR-10 数据集，实现了 SimpleCNN 与 ResNet18 迁移学习两种图像分类方案。SimpleCNN 作为基线验证了卷积神经网络的基本分类能力，ResNet18 通过迁移学习（微调）取得了 95.18% 的测试准确率，充分体现了预训练模型在小数据集上的优势。

### 7.2 问题与反思

实验中遇到的问题及解决：

1. **数据下载慢**：CIFAR-10 官方源在国内下载极慢，通过使用国内镜像手动下载并校验 MD5 解决。
2. **迁移策略与学习率设置**：最初冻结骨干仅得 81%；改为全量微调后，又因学习率 1e-4 过低、配合余弦退火导致中后期收敛停滞，最终把学习率调回 1e-3 后准确率才明显提升。
3. **显存约束**：全量微调时 224×224 输入占用显存较大，将批大小从 128 降到 64 后稳定训练。

### 7.3 课程收获与心得

通过本项目，完整实践了图像分类的全流程，加深了对卷积神经网络各组件、残差结构与迁移学习原理的理解，也体会到「调参不是玄学，而是基于观察和分析的迭代」。数据预处理、模型选择与学习率设置等细节，都会显著影响最终效果。
